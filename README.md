# Personal CV Website

A responsive personal curriculum vitae (CV) website that presents my profile, education, technical skills, projects, experience, and certifications.

## Live Website

Vercel: https://YOUR-PROJECT.vercel.app

## Features

- Responsive layout for desktop, tablet, and mobile
- Sticky navigation bar with smooth scrolling and a mobile menu
- Animated skill bars, scroll reveal effects, and a loading screen
- Project and certificate cards with hover effects
- Sections: Profile, About, Education, Skills, Projects, Experience, Achievements, and Contact

## Technologies Used

- HTML5
- CSS3 (Flexbox, Grid, media queries, animations)
- JavaScript (DOM manipulation, Intersection Observer)
- Google Fonts (Poppins)
- Git and GitHub
- Vercel (deployment)

## Run Locally

1. Clone the repository: `git clone https://github.com/Denn88/personal-cv.git`
2. Open `index.html` in a browser, or use the Live Server extension in VS Code.
